# HP: Prisoner of Azkaban Xbox port

Static recompilation of the original Xbox game on the xboxrecomp toolkit (repo root) with the game project in
`port/`. **Read [port/DEVELOPING.md](port/DEVELOPING.md) first**: setup, regenerating `port/src/recomp/gen/` from
`game/default.xbe`, building, the run folder, debugging tools, engine facts and open issues.

State: M2 merged (boots to the title + attract loop at 60 fps); start from the newest `docs/superpowers/HANDOFF-*.md`, then [docs/bringup.md](docs/bringup.md) and the plans in `docs/superpowers/`.

Essentials:

- Build natively on Windows with MSYS2 UCRT64 (GCC, CMake, Ninja, Python + capstone). From PowerShell:
  `$env:MSYSTEM="UCRT64"; C:\msys64\usr\bin\bash.exe -lc "cd /d/<repo>/port && cmake --build build-win -j$(nproc)"`.
- `port/src/recomp/gen/` is generated by `port/regen.sh`; never edit it by hand. Overrides live in
  `port/src/hle_*.c` and `port/src/scda/xdk/hle_d3d8.cpp`; a new override file must be added to regen.sh's
  `--exclude-manual` list.
- hppoa.exe runs only when started by hppoa_launcher.exe (or with `HPPOA_LAUNCHER=1`), one copy at a time. Before
  replacing exes or rebuilding into a folder the game runs from, check that the game is not running; never close a
  game someone else started.
- Tell the person before starting a test run of your own (it opens on their screen) and close it afterwards; they
  play-test with their own controller and report back, so don't drive their test runs with scripted input.
- Follow the working rules in DEVELOPING.md section 8: faithful translation (no hacks over host quirks), debug
  data and other recomps before home-grown fixes, one test run should answer every open question, compare with the
  original console before "fixing" odd behaviour.
- Nothing from the game goes into the repository (game files, gen/, tools/*/output/, captures, reports,
  artwork). Don't delete whole output folders (dist/, run/).
- Every address in hand-written code must be a PoA function start (`port/tools/check_no_foreign_addrs.py`, run by
  regen.sh). Move addresses from another title with `tools/xdk_port`, never by hand; record evidence in
  docs/bringup.md or docs/re-notes.md (randomizer-relevant finds: pickups, collectibles, spells, scripts).
- Bulk reading (generated code, logs, diffs) goes to DeepCode (`deepcode -x -p "<one-line prompt>"`, no shell, this folder only; see the newest handoff), Codex or agy, read-only.
