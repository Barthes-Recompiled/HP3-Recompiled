## Gotchas

- Bash heredocs eat backslashes and turn `\n` into newlines in Python string edits: use the Edit tool.
- A new override file needs: CMakeLists entry, regen.sh `--exclude-manual`, an `extern void sub_X_gen(void);` line
  (the generator only keeps `_gen` bodies it sees declared), then regen.
- RECOMP_CAPTURE_AFTER=a:b:n with tiny b captures consecutive frames; frame.txt now names each draw's caller.
- Keep game runs short and closed (PC heat); don't run while another session's game runs.
